# Stage 2 source registry

Accessed 2026-10-18. GitHub API queries succeeded. Official web pages were retrieved with the page tool; direct sandbox outbound hosts remain restricted. PDF parser returns at most 30 pages, so later pin/land-pattern pages were **not** independently inspected through that tool. Product summaries are not substitutes for a full pre-layout datasheet audit.

## Verified repository sources

* **P1 — Stable baseline:** [PX4 v1.17.0 release](https://github.com/PX4/PX4-Autopilot/releases/tag/v1.17.0), published 2026-05-13; latest non-prerelease reported by GitHub API on audit date. Commit [`d6f12ad1c4f70ad3230afd7d86e971421e02fef4`](https://github.com/PX4/PX4-Autopilot/tree/d6f12ad1c4f70ad3230afd7d86e971421e02fef4).
* **P2 — Official NXT target:** [stable board directory](https://github.com/PX4/PX4-Autopilot/tree/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/boards/hkust/nxt-dual). Verified `default.px4board`, `bootloader.px4board`, `firmware.prototype`, `src/{board_config.h,hw_config.h,init.c,spi.cpp,i2c.cpp,timer_config.cpp}`, `nuttx-config/{include/board.h,include/board_dma_map.h,nsh/defconfig,bootloader/defconfig,scripts/script.ld}`, `init/rc.board_sensors`, `init/rc.board_defaults`. Local snapshots under `research/px4-v1.17.0/`.
* **P3 — Main comparison:** [board directory](https://github.com/PX4/PX4-Autopilot/tree/ddcaad6601be20453ec6acd0f08e567af3a7e1bb/boards/hkust/nxt-dual). Main reset change: [633af612](https://github.com/PX4/PX4-Autopilot/commit/633af12ea41c739171cdf04fc190c6f6bcc71bef); local comparison subset in `research/px4-main/`. Main and stable are not interchangeable.
* **P4 — Driver evidence:** [BMI088 selection in target](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/boards/hkust/nxt-dual/default.px4board), [barometer Kconfig](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/drivers/barometer/Kconfig), [BMP388 driver](https://github.com/PX4/PX4-Autopilot/tree/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/drivers/barometer/bmp388), [SPL06 driver](https://github.com/PX4/PX4-Autopilot/tree/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/drivers/barometer/goertek/spl06). Stable common barometers selects BMP388 and SPL06. Existence ≠ measured operation on ROXX.
* **P5 — Alternatives:** [FMUv6C](https://github.com/PX4/PX4-Autopilot/tree/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/boards/px4/fmu-v6c), [Durandal](https://github.com/PX4/PX4-Autopilot/tree/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/boards/holybro/durandal-v1). Main default target configs retrieved; stable target presence/release assets verified. These are BSP references, not grants to copy separate commercial board CAD.
* **ST1 — Package pin data:** [ST XML at pinned commit](https://github.com/STMicroelectronics/STM32_open_pin_data/blob/7d1f1514ed5583ec5007ad91236b4e1d377295b1/mcu/STM32H743VITx.xml). LQFP100; BSD-3-Clause license in same repository. Pin-allocation generator checks position/function membership, not NuttX AF macro selection.

## Official documentation / manufacturer sources

* **D1:** [PX4 porting guide](https://docs.px4.io/main/en/hardware/porting_guide), [NuttX guide](https://docs.px4.io/main/en/hardware/porting_guide_nuttx), [manufacturer support guide](https://docs.px4.io/main/en/hardware/board_support_guide). Reviewed; H7 NuttX bootloader, unique target/identity, maintenance and physical evidence obligations.
* **D2:** [PX4 Pi companion wiring](https://docs.px4.io/main/en/companion_computer/pixhawk_rpi), [MAVLink peripherals](https://docs.px4.io/main/en/peripherals/mavlink_peripherals), [offboard mode](https://docs.px4.io/main/en/flight_modes/offboard). First page reviewed; latter two are follow-up configuration references, not proof of tested setup. The generic Pi tutorial's device node/overlay examples must not be blindly used on Pi 5.
* **M1:** [STM32H743 datasheet DS12110](https://www.st.com/resource/en/datasheet/stm32h743vi.pdf) — retrieved first chunks; 480 MHz family, 2 MB variant, approximately 1 MB SRAM, supply and peripheral capabilities. [RM0433](https://www.st.com/resource/en/reference_manual/rm0433-stm32h742-stm32h743753-and-stm32h750-value-line-advanced-armbased-32bit-mcus-stmicroelectronics.pdf) and [ES0392 errata](https://www.st.com/resource/en/errata_sheet/es0392-stm32h742xig-stm32h743xig-stm32h750xb-and-stm32h753xi-device-errata-stmicroelectronics.pdf): required review links, **not retrieved/fully audited**. Exact power tables, package drawing, VCAP and silicon revision conditions remain gate items.
* **M2:** [Bosch BMI088 manufacturer page](https://www.bosch-sensortec.com/products/motion-sensors/imus/bmi088/), [datasheet rev 1.9 Jan 2024](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf). Product page verified 2.4–3.6 V VDD, 1.2–3.6 V VDDIO, 5.15 mA full-operation consumption, 3 × 4.5 mm package. PDF later pin/landing pages unavailable through limited parser; verify full PDF before CAD. Vendor page displayed zero stock across listed distributors; this is not a confirmed worldwide supply result, and quotes are required.
* **M3:** [BMP388 datasheet rev 1.7](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmp388-ds001.pdf), electrical table page 7 retrieved: 1.65–3.6 V VDD, 1.2–3.6 V VDDIO, 800 µA pressure peak maximum, 400 µA temperature measurement maximum. Later package/pin pages require full PDF. Procurement/lifecycle not verified.
* **M4:** Imported SPL06 datasheet link is a [GitHub-hosted copy of Goertek document](https://github.com/iNavFlight/inav/files/3364426/SPL06-001_datasheet.pdf), not an authenticated current manufacturer download. Retrieved cover and §5.3: document marked Restricted; **do not vendor/redistribute**. Describes default I2C, SDO address select and CSB pull-up. Manufacturer revision/authenticity and current availability unresolved; not a release-qualified source.
* **M5:** [MPS MP9943 manufacturer datasheet](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP9943GQ-Z/document_id/865/) retrieved: 4–36 V operating input, 40 V absolute maximum, **3 A peak**, 0.792 V typical feedback, 55°C/W reference θJA. [Richtek RT9013 product page](https://www.richtek.com/Products/Linear%20Regulator/Single%20Output%20Linear%20Regulator/RT9013) retrieved: EOL, 2.2–5.5 V, 500 mA. Tried datasheet -17/-19 URLs returned 404; exact old GB package data not independently verified.
* **M6:** TI product pages retrieved: [TPS62132](https://www.ti.com/product/TPS62132) (fixed **3.3 V**, 3–17 V, 3 A, active), [LP5907](https://www.ti.com/product/LP5907) (2.2–5.5 V, 250 mA, active), [LM61460-Q1](https://www.ti.com/product/LM61460-Q1) (3–36 V, 6 A, active). Datasheet links: [TPS6213x](https://www.ti.com/lit/gpn/TPS62132), [LP5907](https://www.ti.com/lit/gpn/LP5907), [LM61460-Q1](https://www.ti.com/lit/gpn/LM61460-Q1). Direct PDF fetches failed; detailed component/loop/thermal design remains unverified. TPS62133 is the **5 V** variant and is NOT the proposed 3.3 V part.
* **M7:** [Raspberry Pi power documentation](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#power-supply) plus verified [official source](https://github.com/raspberrypi/documentation/blob/ddea98e98dafe9419feb4fd82710c2fbdef7dc44/documentation/asciidoc/computers/raspberry-pi/power-supplies.adoc): 5.1 V, Pi 5 recommended 5 A supply; USB aggregate limit 1.6 A with capable supply, otherwise 600 mA. [Pi UART configuration](https://www.raspberrypi.com/documentation/computers/configuration.html#configure-uarts) is a required OS-specific follow-up; large document not fully reviewed.
* **M8:** [Luxonis OAK-D Lite](https://docs.luxonis.com/hardware/products/OAK-D%20Lite) reviewed: 2.5–3 W base/streaming + up to 1 W AI + 0.5 W stereo + 0.5 W encoder. [Manufacturer-hosted datasheet repository](https://github.com/luxonis/depthai-hardware/blob/master/DM9095_OAK-D-LITE_DepthAI_USB3C/Datasheet/OAK-D-Lite_Datasheet.pdf). USB supported; actual camera hardware revision/power peaks still need bench test. Website contains a baseline-unit inconsistency (75 cm vs linked 75 mm); do not use web prose as a mechanical drawing. Pi USB3 is the system bandwidth bottleneck irrespective of camera's advertised maximum.

No live authorized-distributor quotes, supply reservations, lab measurements or production certificates were obtained. Links marked follow-up/unretrieved are not represented as verified evidence.

Additional alternate IMU evidence: [ICM42688P stable driver directory](https://github.com/PX4/PX4-Autopilot/tree/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/drivers/imu/invensense/icm42688p) and FMUv6C default config explicitly enable it. TDK [DS-000347 download](https://invensense.tdk.com/wp-content/uploads/2020/04/ds-000347_icm-42688-p-datasheet.pdf) redirected to a login/download page; full datasheet not obtained, so no numerical electrical comparison or footprint approval is claimed.
